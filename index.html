LivePortrait 기반 얼굴 모션에서 optical flow, dense warping field, semantic mask를 활용해 event-like representation을 생성하고 비교하는 실험 페이지입니다.

Pipeline Comparison

동일한 LivePortrait 기반 모션을 입력으로 사용하되, motion source와 event 생성 경로를 다르게 구성했습니다.

Baseline

v2e

LivePortrait 생성 동영상을 기존의 이벤트 시뮬레이터인 v2e에 입력합니다.

Pipeline A

RAFT Optical Flow

LivePortrait 생성 동영상에서 RAFT로 optical flow를 추출한 뒤, 각 생성 프레임의 공간 밝기 기울기를 계산하여 event 생성 수식을 적용합니다.

Pipeline B

Dense Warping Field

LivePortrait 중간 생성물인 dense warping field를 활용하며, 각 생성 프레임의 공간 밝기 기울기를 계산하여 event 생성 수식을 적용합니다.

Pipeline C

Dense Warping Field + Frame Warping

LivePortrait 중간 생성물인 dense warping field를 직접 사용해 frame을 warping하고 event 생성 수식을 적용합니다.

Pipeline D

Dense Warping Field + Semantic mask

dense warping field와 semantic mask를 결합해 semantic flow를 구성하고, frame 간 빛 변화 기반으로 event를 생성합니다.

Results

polarity가 명확히 분리되는 event-like stream과 semantic mask 기반의 sparse motion response를 비교합니다.

Global facial motion events

전체 얼굴 움직임에서 발생하는 polarity event를 넓은 시야로 시각화한 결과입니다.

Semantic-flow-guided events

semantic mask를 활용해 의미 영역 중심으로 motion response를 제한한 결과입니다.
